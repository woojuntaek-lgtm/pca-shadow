# 주성분 그림자극

단위만 바꿨는데 첫 주성분이 바뀌었다? — 주성분 분석(PCA)을 손으로 체험하는 앱입니다. 같은 200명의 키를 cm·m·표준화로 바꿔 그리는 첫 장면(78.25% / 99.99% / 약 77.6%), 직선을 돌려 그림자의 분산이 가장 큰 방향 찾기, 공분산 행렬을 바꾸면 타원과 고유벡터가 따라 변하는 고유값 분해, 퀴즈 ①(90%), 붓꽃 150개의 스크리 그림과 누적 비율(92.5% → 97.8%), 키 단위를 연속으로 바꿔 보는 단위의 함정과 표준화, 공분산 고유값과 특잇값 분해 σ²/(n−1) 비교, XᵀX를 만들면 생기는 계산 오차, 사이킷런 코드와 붓꽃 2차원 투영, 동그라미 속 동그라미와 작은 분산에 숨은 신호(PCA의 한계), 퀴즈 ②(np.mean = 3), 잠재 요인 하나로 빈칸을 채우는 추천 행렬 분해까지 담았습니다. 선형대수 13 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 그림자: 첫 장면, 그림자 분산
- ② 고유값: 공분산 행렬과 고유값 분해, 퀴즈 ①, 붓꽃 스크리 그림
- ③ 단위·SVD: 단위 바꾸기와 표준화, SVD 비교, 계산 오차, 사이킷런 코드와 붓꽃 투영
- ④ 한계·추천: 휘어진 구조, 작은 축의 신호, 퀴즈 ②, 평점 빈칸 채우기, 코드, 세 줄 정리, 생각해 볼 질문

고유값 분해(야코비)와 특잇값 분해(단측 야코비)는 모두 브라우저에서 직접 계산합니다. 키·몸무게 200명은 원고 메모의 방식(numpy default_rng(1), 키 N(170, 8), 몸무게 = 0.6(키−170) + N(65, 8))으로 만든 모의 데이터를 소수 둘째 자리로 담았습니다. 붓꽃 데이터는 사이킷런 load_iris(Fisher, 1936)의 공개 데이터입니다. 동그라미 데이터와 작은 축 신호 데이터는 설명용 모의 데이터입니다. 6×5 평점표는 원고에 나오지 않아 새로 만든 가상 평점으로, 원고가 말하는 복원값(4.2, 3.9, 1.7, 1.9)과 맞도록 구성했습니다.
