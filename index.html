🧪 공분산 없이, 특잇값 분해로

붓꽃 데이터. 왼쪽은 공분산 행렬의 고유값, 오른쪽은 평균 뺀 데이터 행렬을 바로 특잇값 분해한 σ²/(n−1).

V의 열 = 주성분 방향. 부호(±)는 어느 쪽을 앞으로 볼지의 차이일 뿐 같은 축입니다.

⚠️ 왜 굳이 SVD? 전치를 곱하면 생기는 오차

열 두 개가 아주 비슷한 3×2 행렬 [[1,1],[ε,0],[0,ε]]. 진짜 작은 특잇값은 ε. XᵀX를 만들면 1 + ε²가 컴퓨터에서 1로 뭉개집니다.

ε = 10^-9

❓ 퀴즈 ② 영화 세 편 중 두 편에 5점, 4점. 안 본 영화는 0으로 적힘. 이 행을 np.mean으로 평균 내면?

🎬 빈칸을 채우는 행렬 분해 (잠재 요인 1개)

사용자 6명 × 영화 5편. 앞의 세 편은 액션, 뒤의 두 편은 로맨스 — 하지만 표에는 장르를 적지 않았습니다. 빈칸 = 안 본 영화. (평점은 설명용 가상)

🐍 빈칸 평균과 복원 코드

import numpy as np R = np.array([[4,5,0,1,2], [4,0,5,1,2], [1,2,1,0,3], [5,5,2,3,0], [1,0,1,5,4], [0,1,1,5,5]], float) M = R > 0 # 평가한 칸 mu = (R * M).sum(1) / M.sum(1) # np.mean(R, 1)은 0까지 셈! C = np.where(M, R - mu[:, None], 0) # 중심화, 빈칸은 0 U, s, Vt = np.linalg.svd(C) A = s[0] * np.outer(U[:, 0], Vt[0]) + mu[:, None] # 잠재 요인 1개로 복원 print(A.round(2))

📌 세 줄 정리

  1. PCA는 분산이 가장 큰 방향부터 서로 수직인 축을 세우고, 공분산 행렬의 고유벡터가 축, 고유값이 분산이다.
  2. 남길 개수는 고유값으로 계산한 설명 비율로 정하고, 단위가 다르면 먼저 표준화한다.
  3. 실제 계산은 특잇값 분해로 하고, 같은 도구가 추천 시스템의 빈칸도 채운다.
